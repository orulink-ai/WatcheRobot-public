# 公开硬件合同：开环舵机

当前支持的舵机**没有物理位置反馈**。本页说明硬件行为，不代表这份公开快照已通过实机验收。

## 命令不是测量

- `watcher_hw_body_request_position()` 和非空位置订阅返回 `ESP_ERR_NOT_SUPPORTED`；
  NULL 注销保持幂等。
- 历史 POSITION 帧及保留协议编号不是当前测量，不可用来放行运动、推断姿态或恢复限位。
- PWM、命令限位、显式锁定／释放、STOP、ACK/NACK、DONE/FAULT 保留。
  ACK/DONE、命令坐标、PWM 推算角度均不能证明真实位置、未堵转或机械已停；STOP 不是急停装置。

## 清空完整运动范围

**每次**运动前人工清空整个可能行程，保证操作者可随时断电，核对配套 STM32 固件兼容性。
体检先命令 **X90/Y120**，再 X93/Y120 或 X90/Y123。实际起点未知，参考移动本身可能是大行程，
不是归零、标定或实测三度位移。退出时不自动回中。

ESP32 断连后无法送达 STOP。协议完成、重连和排空 FIFO 都不证明机械安全；故障后必须显式
重新初始化并等待新的用户意图，不能自动重放运动。

## 验收边界

host 测试只证明软件状态及序号行为。方向、完整边界和实际停止必须由人工或未来独立夹具确认，
记录配套固件版本、公开源码／构建哈希及逐项结果。历史反馈标定不是当前前提，不能代替物理证据。
SDK 不更新 STM32/Himax 固件。配对兼容性未知或完整官方恢复资产缺失时，**禁止继续烧录**。

参见[安全上手与恢复](getting-started_zh.md)、[26 项体检](hardware-check_zh.md)及
[本次验证事实](../SYNC_VALIDATION.md)。
