# 合并前鲁棒性审查（开发预览）

日期：2026-10-07。范围：新增 SDK 适配层、身体事件运行层、运动结果关联、
显示/音频 BSP 生命周期改动和独立示例。不是对全部第三方驱动的全量审计。

## Blockers

None found（仅针对开发预览合并；完整稳定版发布门禁见 VALIDATION.md）。

## High Risk

已修复：身体静默误失联与 UART 门禁竞争导致永久 FAULT；分发期间关闭或并发
关闭可能使借用上下文/工作任务失效。修复在既有服务与 SDK 生命周期层完成，
不新增第二套 UART 协议。回归测试先失败再通过，超时关闭仍可重试。

## Medium/Low

已修复：通用 ACK/NACK 被误报为运动生命周期；既有运动服务增加有界序列关联，
保留 typed DONE/FAULT（包括停止之前的原运动结果）。最近 32 命令以外的迟到
ACK/NACK 不报告，调用方不应把 ACK 当作完成。板级共享总线与部分 LVGL 缓存
保留至进程结束，这是公开资源约定，不承诺关闭全部回收。

## Missing Verification

完整机械限位、全部灯光分区/触摸类型、JPEG 解码/流重启、PCM 品质、
缺失设备隔离、多核并发压力及恢复官方流程仍待实机验收。先前双 MCU HIL
证明命令执行链路，并非最后审查补充代码的硬件重测或精确机械位置证据。
最终合入必须重新通过 CI；不得据此发布稳定首版。

## No Finding Areas

已检查：模块依赖隔离；有界 FIFO 和溢出计数；每帧触摸复制；未就绪拒绝及
重连不重放；角度/时长校验；JPEG 回调借用约定；音频 codec lease 与单 owner
阻塞约定；标准显示句柄、LVGL 锁、DMA 排空和失败时保留资源的退出路径。
