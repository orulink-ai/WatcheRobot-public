# Resources and downloads

## Hardware and parts {#hardware}

| What you need to do | Resource |
| --- | --- |
| Open the original PCB designs | [JLC OSHWHub project (external site)](https://oshwhub.com/team_efhmhuqf/project_gbxcghnl) |
| Download printable models | [MakerWorld model page (external site)](https://makerworld.com.cn/zh/models/2911544-watcherobot) |
| Source assembly parts and board components | [Whole-robot assembly BOM (Excel)](pcb/bom/BOM_Assembly_整机组装料.xlsx) · [All BOMs (GitHub directory)](https://github.com/orulink-ai/WatcheRobot-public/tree/main/hardware/pcb/bom) |
| Find PCBs, Gerbers, CPL files, and mechanical models | [hardware (GitHub directory)](https://github.com/orulink-ai/WatcheRobot-public/tree/main/hardware) |

Before fabrication, match the BOM, Gerber, and CPL to the same board revision. Follow [PCB fabrication and SMT assembly](../docs/pcb-fabrication.md) and the [whole-robot assembly tutorial](../wiki/guides/en/guide/assembly.md) for the actual steps.

## Firmware and SD-card assets {#firmware}

Download the firmware and SD-card assets specified in the [latest GitHub Release](https://github.com/orulink-ai/WatcheRobot-public/releases/latest), then follow the [flashing guide](../docs/flashing.md) and [SD-card asset guide](../docs/sd-card-assets.md). Complete assembly and unpowered wiring checks before flashing.

## Versions and compatibility {#versions}

Use the corresponding [Release notes](https://github.com/orulink-ai/WatcheRobot-public/releases) for version provenance and required combinations. Match head firmware, body firmware, and SD-card assets as instructed; ask the [community](../wiki/guides/en/products/watcherobot/community.md#report) about unspecified combinations rather than guessing compatibility from filenames or version numbers.
