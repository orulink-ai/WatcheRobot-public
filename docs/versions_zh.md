# 版本来源

公开使用者以 [Latest Release](https://github.com/orulink-ai/WatcheRobot-public/releases/latest) 为下载入口。正文不固定具体版本号；每次发布时由 Release 页面记录各部分版本。

| 部分 | 版本信息位置 |
| --- | --- |
| 整套公开发布 | Release 标签和说明 |
| STM32、Himax、ESP32-S3 | Release 说明及固件包名称 |
| SD 卡资源 | Release 说明及资源包名称 |
| Windows、macOS、Android、iOS | Release 说明和对应下载入口 |
| Python SDK | Release 说明、wheel 名称和 `python-sdk/pyproject.toml` |
| 硬件资料 | `hardware/` 中的生产文件 |

仓库根目录的 `VERSION` 表示仓库资料包版本，不代替各组件的发布版本。
