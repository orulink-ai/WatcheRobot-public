# Release 版本

说明文档不固定产品版本号。请以 [GitHub Releases](https://github.com/orulink-ai/WatcheRobot-public/releases) 中标记为 **Latest** 的 Release 为准。

- 组件版本：查看 Release 说明和 `WatcheRobot-Bundle-*.manifest.json`。
- 文件校验：查看 `SHA256SUMS.txt`。
- Python SDK 源码：查看 `python-sdk/` 子模块提交。
- 硬件资料：查看 `hardware/` 当前内容。

如果附件类型、运行环境、硬件要求或操作顺序发生变化，应同步更新中英文说明。
