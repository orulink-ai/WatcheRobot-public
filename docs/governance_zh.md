# 仓库规则

- Python SDK 使用 `python-sdk/` 子模块。
- 硬件资料放在 `hardware/`。
- 当前 C SDK 在 [WatcheRobot_c_sdk](https://github.com/orulink-ai/WatcheRobot_c_sdk) 独立维护；本仓库 `firmware/sdk/` 为历史预览快照，保留 Apache-2.0 与第三方原有许可证。
- 官方 ESP32 应用、STM32F103、Himax、App、服务端和桌面端实现不放入本仓库。
- 固件、客户端安装包和 SD 卡资源只上传到 GitHub Releases。
- 私有路径、账号、凭据和内部日志不得写入公开文档。
