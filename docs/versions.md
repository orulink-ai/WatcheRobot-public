# Version Sources

Public users should start from the [Latest Release](https://github.com/orulink-ai/WatcheRobot-public/releases/latest). These guides do not pin product versions; each Release records its component versions.

| Area | Where to find its version |
| --- | --- |
| Complete public release | Release tag and notes |
| STM32, Himax, ESP32-S3 | Release notes and firmware package names |
| SD-card resources | Release notes and resource archive name |
| Windows, macOS, Android, iOS | Release notes and download entry |
| Python SDK | Release notes, wheel name, and `python-sdk/pyproject.toml` |
| Hardware files | Production files under `hardware/` |

The root `VERSION` identifies the repository material package; it does not replace component release versions.
