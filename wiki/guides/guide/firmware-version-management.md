# 固件版本管理

固件版本切换、恢复出厂设置和 USB 救援处理的是不同问题。恢复出厂设置不会改变固件版本；升级或降级需要在 Watcher Desktop 中通过 USB 完成。

## 在客户端切换固件版本

Watcher Desktop 会先把所选固件包下载到电脑并完成校验，然后才通过 USB 将固件写入设备。

开始前：

- 使用 USB 将设备连接到电脑，并保持设备稳定供电；
- 在客户端中选择正确的设备、串口和固件版本；
- 关闭正在占用同一串口的串口监视器或其他程序。

开始后，请等待客户端依次完成固件包下载、校验、USB 烧录和设备重启。客户端显示完成前，不要断开 USB 或关闭设备电源。

::: info 固件包下载失败不会改写设备
固件包在电脑上下载或校验失败时，USB 烧录尚未开始，设备会继续运行原来的固件版本。检查网络后重新下载即可。
:::

## 恢复出厂设置

需要清除设备上的网络、配对和服务连接信息，或者准备将设备交给其他人使用时，可以执行恢复出厂设置。

::: warning 固件版本不会改变
恢复出厂设置不会安装、升级或降级固件。设备重启后仍然运行操作前的固件版本。
:::

恢复出厂设置会清除或重置：

- 已保存的 Wi-Fi 名称、密码和连接配置；
- 屏幕亮度和系统音量，二者会恢复为固件默认值；
- 客户端配对信息和配对密钥，设备需要重新与客户端配对；
- 语音服务使用的连接地址、账号、密码或访问令牌等本机配置；
- 设备在本机保存的身份标识和内部运行状态。设备身份标识会在后续启动时重新生成。

恢复出厂设置不会删除：

- 当前安装的固件；
- SD 卡中的照片、录音或其他文件；
- 由 Watcher Desktop 和 SDK Daemon 在电脑上管理的 Application。

### 操作步骤

1. 在设备上打开 **Settings**。
2. 进入 **Factory Reset**。
3. 按照屏幕提示滑动确认。
4. 等待设备自动重启。重启完成前不要关闭电源。

### 重置后重新连接

设备重启后，请重新连接 Wi-Fi，再通过 Watcher Desktop 完成设备配对。如果使用语音服务，还需要按照客户端提示重新配置或激活服务。屏幕亮度和系统音量可以在设备设置中重新调整。

## 固件安装中断时

恢复出厂设置不能修复没有完整写入的固件。处理方式取决于中断发生在哪个阶段：

| 中断阶段 | 设备是否已经被改写 | 处理方式 |
| --- | --- | --- |
| 客户端正在下载或校验固件包 | 否 | 检查网络后重新下载 |
| USB 烧录已经开始 | 可能已经写入部分内容 | 保持或重新连接 USB，再次执行完整烧录 |
| 烧录后设备无法正常启动 | 当前固件可能没有完整写入 | 使用客户端重新烧录官方固件；必要时让设备进入 USB 下载模式后重试 |

USB 烧录会写入启动程序、分区表和主固件。烧录过程中断开 USB 或设备掉电，可能导致设备无法正常启动，不能保证设备会自动恢复到原来的版本。

## USB 有线救援

设备无法正常启动或客户端无法连接设备时，请保持 USB 连接，并在客户端中重新烧录适用于该设备的官方固件。除非官方操作说明明确要求，否则不要执行整机擦除。

## 选择正确的操作

| 你的目标 | 使用的功能 | 固件版本是否改变 |
| --- | --- | --- |
| 升级或降级 | 客户端 USB 固件烧录 | 是 |
| 清除网络、配对和本机服务配置 | 恢复出厂设置 | 否 |
| 固件包下载失败 | 在客户端重新下载 | 否 |
| USB 烧录中断或设备无法启动 | 重新执行 USB 固件烧录 | 由重新选择的固件版本决定 |
