# 用 AI Agent 创建应用

描述你的想法，让 AI Agent 帮你把它做成 WatcheRobot 应用。

推荐使用 **WatcheRobot App Skill**：它把开发流程、应用模板和机器人能力说明交给 Agent，让你从需求开始，而不是先翻完 SDK 手册。

## 01 · 复制这句话给 Agent

打开能读取链接、编辑本地文件并运行命令的 AI 编程工具，例如 Codex、Claude Code 或 TRAE，在你的项目工作区发送下面这句话。把最后的需求替换成你自己的想法。

<SkillPrompt />

[下载完整 Skill ZIP](/downloads/watche-robot-app.zip) · <a href="/downloads/watche-robot-app/SKILL.md" download>下载 SKILL.md 原文</a>

这是一段发给 Agent 的提示词，**不是终端安装命令**。它让 Agent 获取本次任务所需的完整 Skill，不保证自动安装为所有工具的永久技能。若 Agent 无法下载链接，手动下载 ZIP 并解压到本机，将 `watche-robot-app` 文件夹交给它，再让它读取其中的 `SKILL.md`；仅粘贴 SKILL.md 内容不包含配套模板和脚本。

## 02 · 告诉它你想做什么

先做一个可以验证的小功能，说明触发方式、机器人行为和完成结果。例如：

> 我想做一个触摸互动程序：触摸机器人背部后，灯光变蓝并播放一个设备中实际存在的表情。重复触摸时不要叠加任务，停止程序时释放自己占用的资源。先完成代码和本地检查，等我确认后再连接机器人测试。

也可以做网页按钮拍照、定时提醒，或接入自己的语音服务。涉及表情、动作或音效时，让 Agent 查询真实资源，不猜测资源 ID；需要云服务时使用你自己的凭据，不把密钥写进代码或聊天记录。

## 03 · 让 Agent 创建并检查

Skill 包含单次任务、输入监听和网页按钮等应用模板，以及运动、灯光、表情、音频、相机、触摸、RTC 等能力说明。Agent 按需求选取模板，准备隔离环境、核对实际 SDK 接口，再编写和检查程序。

- **准备条件**：电脑具备 Python 3.10—3.12（推荐 3.11），并可联网安装 SDK；Agent 需要文件和终端权限。缺少条件时先让它说明并协助准备。
- **交付结果**：项目文件夹、检查结果、完整启动命令和使用方式。
- **运行方式**：程序在电脑上运行，通过 SDK Daemon 控制机器人，使用 `watcherobot app run` 启动，不是直接刷入设备的固件。

## 04 · 连接机器人，看真实效果

本地检查通过后，再按[Python SDK 快速开始](/docs/sdk)连接机器人。没有设备也可以先生成并检查代码，但要把真机效果标为待验证。

让 Agent 在运行前确认当前设备和占用情况，不接管其他正在运行的应用。运动测试需留出安全空间；当前舵机没有物理位置反馈，命令成功不等于实测到位。

停止应用后，检查它是否释放资源。拍照成功要看到真实照片，声音和动作要实际验收；不能把构建成功或命令返回成功当成效果完成。
