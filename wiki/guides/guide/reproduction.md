# 复现指引

从零件开始，制作出一台能够开机、联网、显示表情并执行动作的 WatcheRobot。本页按制作顺序展开：**确认物料 → 打印结构件和制作 PCB → 采购其余零件 → 装配接线 → 安装固件与资源 → 整机检查**。打印和 PCB 打样可以同时安排，不必先配置软件环境。

这里的复现使用现成的 **Watcher 头部模块、定制舵机和公开的身体硬件设计**，不是从裸芯片重新设计头部，也不要求编译官方嵌入式源码。已有可用整机的用户请看[快速开始](getting-started.md)。

## 1. 确认要制作的部件 {#parts}

先下载[整机组装 BOM](../../../hardware/pcb/bom/BOM_Assembly_整机组装料.xlsx)，对照下表区分“购买成品”和“自行加工”。BOM 文件较大，建议下载后查看；型号、数量、螺丝和线材规格以清单及对应装配图为准。

| 部件 | 获取方式 | 开始制作前确认 |
| --- | --- | --- |
| Watcher 头部 | 采购对应头部模块，或联系项目方确认采购渠道 | 与身体结构、接口和配套固件兼容，不用普通 ESP32 开发板替代 |
| 定制舵机 | 联系项目方确认型号和采购方式 | 外形、连接方式和反馈接口匹配，不只按外观选普通舵机 |
| 身体、底座等结构件 | 下载模型，自行 3D 打印或委托打印 | 模型版本、零件数量和打印要求 |
| PCB 电路板 | 按公开工程打板，再自行焊接或委托 SMT 贴片 | 裸板不等于焊好元件的成品板 |
| 线材、螺丝及其余组装料 | 按整机 BOM 配齐；线材也可向项目方咨询配套包 | 接头、线序、长度、螺丝规格与安装位置匹配 |
| 电池及供电配件 | 按 BOM 和装配说明采购 | 规格、插头和极性匹配，不能仅凭插头能插入判断兼容 |

定制件渠道或规格不清楚时，先通过[项目社区](../products/watcherobot/community.md)向维护者确认，再安排其余采购。还需要准备螺丝刀、镊子、万用表；自行焊接时准备焊接工具。ST-LINK V2、USB 数据线、SD 卡和读卡器用于后面的烧录与调试。

## 2. 下载模型并打印结构件 {#printing}

1. 打开 [MakerWorld 模型页面](https://makerworld.com.cn/zh/models/2911544-watcherobot)，下载用于打印的模型及配套说明。
2. 按模型发布者提供的零件数量、材料、摆放方向和支撑要求，自行打印或交给打印服务商。不要将整机装配 STEP 直接当作单个零件切片打印。
3. 打印完成后去除支撑和毛刺，对照零件清单清点；试装螺丝孔、PCB 固定位置和舵机安装位置，确认没有明显变形或干涉，再进入正式装配。

需要查看部件之间的装配关系或修改结构时，使用仓库中的[整机装配 STEP](../../../hardware/3d-models/exports/WatcherRobot-mian.stp)。它用于查看和编辑结构；打印参数仍需按对应模型说明确认。

**完成这一步后：**得到清点过、可试装的结构件，而不只是下载了模型。

## 3. 制作 PCB 并完成焊接 {#pcb}

打开[立创开源硬件工程](https://oshwhub.com/team_efhmhuqf/project_gbxcghnl)，找到需要制作的板卡。当前仓库提供以下四类板卡资料；具体使用数量按整机 BOM 核对：

| 板卡 | 仓库文件标识 |
| --- | --- |
| 反馈舵机 STM32 控制板（身体主板） | STM32Servo |
| 脚底充电板 | FootCharger |
| 无线充电底座板 | WirelessBase |
| 侧边灯板 | SideLight |

### 打板

1. 在工程的“设计图”中选择目标板卡，点击“在编辑器中打开”，进入嘉立创 EDA。
2. 核对工程版本，使用“导出 → PCB/FPC 一键打样”生成生产资料并进入下单流程。修改过电路或 PCB 时，先检查设计规则和连接关系。
3. 按对应板卡工程核对层数、板厚、尺寸、数量及工艺要求。不要将一块板的参数直接套用到其他板卡。
4. 核对预览与报价后，自行确认订单。

带界面截图的操作见[如何获取 PCB 板子](https://mcnsslrwxv50.feishu.cn/wiki/YSAlwY4EZiuR0jkYcu2ctHzKn3R)（以 STM32 控制板为例）。页面按钮可能随平台更新变化。

也可以将仓库内对应板卡的 [Gerber 生产文件](../../../hardware/pcb/gerber/)交给 PCB 厂商。Gerber 用于生产裸板；可编辑工程在 [pcb-source](../../../hardware/pcb/pcb-source/)，原理图与 PCB 布局 PDF 用于核对设计，不是直接替代 Gerber 的生产文件。

### 焊接或 SMT 贴片

- **委托 SMT：**使用同一版本板卡的 [BOM](../../../hardware/pcb/bom/) 和 [CPL 坐标](../../../hardware/pcb/cpl/)，逐项核对型号、封装、贴装面、方向与极性；缺料替代需确认电气和机械兼容性。
- **自行焊接：**按 BOM、[原理图](../../../hardware/pcb/schematic/)和[布局图](../../../hardware/pcb/layout/)装配元件。选择部分 SMT 时，收货后还要补焊未贴装的器件。

收货后检查错件、漏件、反向元件、虚焊和连锡；断电检查电源与地是否存在异常短路。未确认前不要接电池或头部。

**完成这一步后：**得到已焊接并检查过的板卡，而不只是裸 PCB。

## 4. 清点零件，完成装配和接线 {#assembly}

结构件和 PCB 制作期间，按第 1 步的 BOM 采购其余零件。到货后分类摆放，先检查型号、数量与接口，再开始装配；不要用规格不明的螺丝或线材凑装。

打开[机器人拼装图文](https://mcnsslrwxv50.feishu.cn/wiki/PNhqwdCVEiqizvkelq9c2q7Qnth)，对照实物照片完成下列工作。具体孔位、排线朝向、线序和螺丝长度要看对应图片，不能仅凭下面的文字或导线颜色接线。

| 装配部分 | 需要完成的工作 | 检查要点 |
| --- | --- | --- |
| 头部与身体主板 | 预先穿线、连接头部与主板、固定对应结构件 | 接口与照片及板上标识一致，不压住线缆 |
| 舵机与身体机构 | 安装舵机、连接身体主板、按图检查复位与安装姿态 | 不靠强扭舵机或强锁舵盘纠正错位 |
| 灯板与触摸部件 | 安装灯板、连接排线与触摸部件 | 排线方向与锁扣正确，导电部件不误碰其他焊点 |
| 脚部与底座 | 安装对应结构件、底部 PCB 和相关连接线 | 孔位对齐，线缆留有活动余量，不进入运动夹缝 |
| 电池与外壳 | 核对供电连接，整理内部线材，再固定盖板 | 电池不断裂、不挤压，螺丝不顶住电池或电路板 |

装配和插拔排线时保持断电。图文中的舵机复位检查若需要上电，应先完成接线检查，并确认身体主板已有可用的配套固件；新制主板尚未烧录时，先按下一节完成 STM32 烧录，再继续复位检查。不要将“新板未响应”直接判断为舵机损坏。

封盖前确认烧录口和 SD 卡仍可访问。线序或安装姿态无法从资料中确认时暂停对应步骤，向维护者核实，不要尝试带电试错。

**完成这一步后：**结构固定可靠，线缆无夹伤，供电极性和接口检查完成，运动机构无明显干涉。

## 5. 安装固件和 SD 卡资源 {#firmware}

到这里再准备电脑软件环境，不需要在打印和采购之前安装 SDK。

1. 从[公开仓库](https://github.com/orulink-ai/WatcheRobot-public)下载并解压代码 ZIP，获取烧录工具；熟悉 Git 时也可克隆。仅复现官方固件，不需要初始化 Python SDK 子模块。
2. 从 [Releases](https://github.com/orulink-ai/WatcheRobot-public/releases) 下载发布说明指定的 STM32、头部配套固件和 SD 卡资源，保持版本组合匹配。
3. 按[完整烧录指南](../../../docs/flashing_zh.md#full)准备环境，用 ST-LINK V2 烧录 STM32，再通过 USB 完成 ESP32-S3 / Himax 头部烧录。
4. 按[SD 卡资源指南](../../../docs/sd-card-assets_zh.md)格式化并写入资源，断电后将卡插回头部。

可以让 AI 编程助手阅读[发布固件烧录 Skill](../../../skills/watche-release-flash/SKILL_zh.md)协助执行。网页烧录只更新 ESP32-S3，不能替代这里的完整安装。

**完成这一步后：**各目标写入与校验成功，SD 卡资源就位；这还不等于所有硬件已通过实机测试。

## 6. 首次开机与整机验证 {#verify}

将机器人放在安全、平整的位置，给运动机构留出空间。开机后先检查屏幕、异常发热、异响和机械卡住；出现异常立即断电排查，不要连续发送动作。

按[快速开始](getting-started.md)完成配网与连接，再按[首次运行检查](../../../docs/action-test_zh.md)逐项验证：

- 屏幕能显示主界面和表情。
- 手机或电脑能实际连接设备。
- 灯光响应，小幅动作方向正常，没有碰撞或持续堵转。
- 需要使用音视频时，再检查扬声器、麦克风和摄像头的实际结果，不能只看“连接成功”。

至此才完成从零件到可用机器人的复现。后续编写应用属于可选步骤，见[SDK 快速开始](../../../docs/sdk_zh.md)。

> PCB 下单和具体装配照片目前仍在上述飞书图文中，可能需要访问权限。本页提供完整制作流程和资料入口，不替代逐个孔位、线序的图示；无法打开图文时请先联系维护者获取资料再装配。
