# 故障排查

从最小范围开始定位问题，不要一开始就清除数据或整片擦除 Flash。

## 客户端找不到设备

1. 确认机器人已经完成启动并保持供电。
2. 确认电脑与机器人位于同一局域网。
3. 暂停其他正在运行的 Watcher Desktop 或 SDK Runtime 实例。
4. 检查防火墙是否阻止本地网络发现。
5. 重启客户端后再次观察设备列表。

## 已配对但无法连接

- 确认设备没有切换到另一个 Wi-Fi；
- 检查局域网是否启用了客户端隔离；
- 先等待自动重连，不要立即删除配对关系；
- 只有确认保存的网络凭据已经失效时才重新配网。

## Application 无法启动

客户端在线不代表 Application 已经运行。确认当前选择的 Application 与固件协议兼容，并查看客户端提供的 Application 状态和日志。

第三方 Application 可以安全忽略不支持的桌面业务帧，但不应要求 Daemon 绕过当前 Application 直达设备。

## 固件维护失败

- 保持供电，不要在写入过程中拔线；
- 记录失败阶段、目标版本和客户端日志；
- 如果固件包尚未下载或校验完成，请检查网络后重新下载，此时设备固件不会被改写；
- 如果 USB 烧录已经开始，请重新连接 USB 并再次执行完整烧录；
- 设备无法启动时使用[USB 有线救援](../guide/firmware-version-management.md#usb-有线救援)。

## 提交问题前

请准备以下信息：

- 客户端版本与操作系统；
- ESP32 与 STM32 固件版本；
- 设备连接方式和网络环境；
- 可复现步骤、预期结果和实际结果；
- 脱敏后的相关日志。
