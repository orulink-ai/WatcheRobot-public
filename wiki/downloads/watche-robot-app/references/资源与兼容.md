# 资源与兼容

需要核查官方源码或查找教程时，见 [SDK 源码与飞书资料](源码与资料.md)。链接仅供按需查阅，安装来源仍按下面规则选择。

## 安装包决定可调用接口，设备决定可执行能力

新项目默认执行正式 PyPI 的 `pip install --upgrade watcherobot`，安装当前 Python 可用的最新稳定版；不固定 SDK 版本，不默认使用预发布或 TestPyPI。实际版本和模块路径写入 `sdk-capabilities.json`。保留官方初始化器生成的兼容声明，不额外改成精确版本锁。已有项目沿用原环境，不因读取本 Skill 就自动升级。

按本次功能检查安装包方法，再检查设备 capability；两者都通过也不等于实机效果已经验收。

| 要用的能力 | 应检查什么 |
|---|---|
| 反馈拍照 | `camera.capture_with_feedback` 与 `camera.capture.feedback.v1`；先结束本应用 RTC |
| 嘴型跟随 | `expression_runtime.set_audio_follow`；按 C04 区分 RTC、本地 PCM 与情绪参数 |
| 连续 PCM 播放 | `audio.open_stream`、`audio_stream.*` 与 `audio.stream.continuous.v1` |
| 设备语音 | `speech.open`、`speech_session.*` 与 `speech.joyinside.v1`；设备已有可用配置 |
| 自选云服务语音 | `cli.voice`；按 C16 使用官方模板和用户自己的服务凭据 |
| 资源诊断 | 需要时再检查 `robot.resource_evidence`；缓存不是实时测量 |
| 完整 RTC 通话 | 控制/信令之外还需匹配设备协议的媒体客户端 |

最新包仍缺少接口时，报告实际版本、模块路径及缺失项，不猜最低版本，不静默换功能。用户指定本地 wheel、源码或其他正式版本时可用 `prepare --sdk <来源>`；切换安装包不等于更新正在运行的共享 Daemon。

## 在哪里取得真实资源 ID

| 资源 | 查询方式与字段 | 没查到时 |
|---|---|---|
| 动画 | 应用内 `robot.animation.available_ids`，每项就是可用动画 ID | 说明无公告资源；可选 C04 程序化表情 |
| 官方表情 | 无 Application 占用时，用本项目 CLI `robot screen list --json`，检查 `official` 列表中返回的真实 `id` | 不假定资源已安装；可选程序化表情 |
| 作品及片段 | 同一目录响应的 `works` 列表；使用条目实际返回的作品标识及片段标识，字段因目录格式而异，先读取返回值 | 缺少字段时要求提供作品清单，不把名称当 ID |
| 视觉模型 | 应用内 `robot.vision.models()`；使用 `model_id`，结合 `name`、`task`、`verified` 选择 | 没有符合任务的模型就说明缺少资源，不默认把第一个当人脸模型 |
| 录制 | 应用内 `robot.recordings.list()`；使用 `id`、`state`、`mode` | 无完成条目时先完成一次录制；不伪造 recording_id |
| 动作、设备音效、组合行为 | 此版公共接口未提供已验证的统一枚举流程；需已安装资源的清单或用户给出的真实 ID | 明确缺项；可提供直接运动、主机音频文件、按顺序组合能力的替代实现，由用户决定是否改变方案 |

`robot screen list` 是设备业务查询：有 Application 时会进入它，不能通过新增直连绕过。不要为查询目录擅自停止别人的应用。优先复用已有可信资源清单；仍缺少时只询问所需资源或继续不依赖资源的部分。

手册中的 `your_*_id` 均是待替换标记。交付前搜索这些标记：不得将未配置示例称为“可直接运行的成品”。

## 已知无法由 skill 单独修复的边界

- 录制启动应答丢失时可能拿不到设备生成的录制 ID。保留有限录制时长，核对目录与状态；无法识别本次录制时报告状态未知，不停止别人的任务、不盲目重试。
- 断线后不要自动重放运动、播放或拍照等有副作用命令。保留错误，恢复连接后由明确的新事件触发。
- 正常托管停止也有有限退出预算（见 D06）；强杀、掉电或断线也可能使清理无法送达。模板只保证尽力清理及错误可见，不保证物理停止。
- POSIX 入口支持开发脚本执行；不代表已验证 Linux 设备连接、媒体栈和应用广场支持。

## 维护验证

`scripts/api-contract.json` 保存能力手册中公共方法的调用参数合同，准备/检查工具用它检查已安装包。新增能力时同步增加合同及其版本条件。属性（例如 available_ids）及返回媒体内容仍需运行验证。

当前 skill 作为一个完整目录分发，保留 scripts、assets、references。已有同类旧 skill 时只选一个主入口；不要同时叠加旧版的安装源、强制界面和新建项目规则。此包不自动修改用户安装的其他 skill。
