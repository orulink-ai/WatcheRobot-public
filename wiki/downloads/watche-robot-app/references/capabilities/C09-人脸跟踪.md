# C09 人脸跟踪

先读 [共同前提 C00](../机器人能力.md)。

**如何选择：** 希望设备自动控制云台跟随人脸选 start；还需图像和检测框选 open_preview。只做检测、不转头使用 C08。

**使用前检查：** start 要求 face_tracking.control.v1；open_preview 要求 face_tracking.preview.v1。配套固件可能要求已选择含人脸类别且通过校验的模型。PTL 跟随预览使用 width=640、height=480，不能依赖 SDK 默认的 416×416。

### 跟踪五秒，保持当前位置停止

```python
from app_support import device_session

if not robot.supports('face_tracking.control.v1'):
    raise RuntimeError("设备未声明 face_tracking.control.v1")

import time

# 启动人脸检测及云台自动跟踪，设备可能开始转动。
with device_session(
    lambda: robot.face_tracking.start(),
    lambda: robot.face_tracking.stop(policy="hold"),
):
    # 让跟踪持续运行 5 秒；不是等待某个人脸任务完成。
    time.sleep(5)
```

### 停止并请求回中

```python
if not robot.supports('face_tracking.control.v1'):
    raise RuntimeError("设备未声明 face_tracking.control.v1")

# 停止时回中；与 policy="hold" 保持当前位置二选一。
# recenter：请求停止跟踪并按设备回中策略复位；返回不等于已完成回中运动。
robot.face_tracking.stop(policy="recenter")
```

### 跟踪并获取预览

```python
if not robot.supports('face_tracking.preview.v1'):
    raise RuntimeError("设备未声明 face_tracking.preview.v1")

# 同时启动人脸跟踪与图像预览；退出 with 时关闭预览并停止跟踪。
with robot.face_tracking.open_preview(
    # width、height：请求的图像宽高，单位像素；stop_policy：退出时保持云台位置。
    width=640, height=480, stop_policy="hold",
) as preview:
    # 最多等待一帧预览 10 秒。
    frame = preview.read(timeout=10)
    # 将当前帧保存为主机上的 JPEG 文件。
    frame.save("tracking.jpg")
    # faces：本帧的人脸框，其中 x、y 表示框的左上角坐标。
    print("人脸：", frame.faces)
    # telemetry：设备随帧返回的跟踪状态信息。
    print("跟踪状态：", frame.telemetry)
```

**成功标准：** 确认人脸位置变化时设备有实际跟随；预览有 JPEG、faces 和 telemetry。控制启动成功不证明运动链路可用。

**失败与清理：** stop(policy='hold') 保持位置；recenter 请求回中。预览 with 退出负责关闭预览与跟踪；不能只丢弃对象而留下设备运动所有权。
