# C11 录制

先读 [共同前提 C00](../机器人能力.md)。

**如何选择：** 保存到设备 SD 卡选 start；直接传回电脑选 start_host；设备屏幕预览是 screen_preview=True；下载的原始格式是 WREC。

**使用前检查：** 设备录制需 recording.device.v1；主机录制需 recording.host.v1；av 另需 recording.device.av.v1；屏幕预览另需 recording.screen_preview.v1。mode 为 video/audio/av，duration 单位秒，fps 为请求帧率。

### 设备录制后下载

```python
if not robot.supports('recording.device.v1'):
    raise RuntimeError("设备未声明 recording.device.v1")

import time

# video=纯视频；audio=纯音频；av=音视频。
mode = "video"
# 在设备 SD 卡上录制；返回本次录制的控制句柄。
recording = robot.recordings.start(
    # mode：上面选择的媒体类型；duration：请求录制 5 秒。
    mode=mode, duration=5,
    # width、height：请求宽高（像素）；fps：请求每秒 5 帧，实际取决于设备。
    width=640, height=480, fps=5,
)
try:
    # 给 5 秒录制留出少量时间，随后显式停止并等待收尾。
    time.sleep(5.5)
finally:
    # 等待设备结束录制并返回最终信息，例如 ID、模式、宽高和帧率。
    info = recording.stop()

download = robot.recordings.download(
    # info.id：要下载的录制 ID；第二个参数：主机上的输出目录。
    info.id, "recording-output",
)
# 下载得到原始 WREC 文件目录；可用后面的转换示例生成 WAV 或 MP4。
print(download.raw_directory)
```

### 主机接收 WREC

```python
if not robot.supports('recording.host.v1'):
    raise RuntimeError("设备未声明 recording.host.v1")

import time
from pathlib import Path
from watcherobot.protocol import FLAG_LAST

# 让设备把录制数据传回主机，由本程序写入文件。
recording = robot.recordings.start_host(
    # mode：纯视频；duration：请求录制 5 秒；fps：请求每秒 5 帧。
    mode="video", duration=5, fps=5,
)
complete = False
try:
    # 本机接收的轮询窗口为 12 秒，为数据传输和结束帧留出时间。
    deadline = time.monotonic() + 12
    # 先写入 .part 临时文件，避免把未完整接收的数据当成成品。
    with open("host-recording.wrec.part", "wb") as output:
        while time.monotonic() < deadline:
            try:
                # 每次最多等待一帧数据 1 秒；短暂无数据时继续轮询。
                frame = recording.read(timeout=1)
            except TimeoutError:
                continue
            # payload 是 WREC 数据字节，按接收顺序写入。
            output.write(frame.payload)
            # 只有收到 FLAG_LAST 结束标志才认为传输完整。
            if frame.flags & FLAG_LAST:
                complete = True
                break
    if not complete:
        raise TimeoutError("主机录制未收到结束帧")
finally:
    try:
        if not complete:
            # 接收失败或超时时，请求设备停止仍在进行的录制。
            recording.stop()
    finally:
        # 释放主机侧接收资源；close 本身不代替设备停止命令。
        recording.close()

# 仅在完整接收且无异常后改为正式文件名；异常时保留 .part 便于排查。
Path("host-recording.wrec.part").replace("host-recording.wrec")
```

### 音视频录制并显示设备预览

```python
if not robot.supports('recording.device.v1'):
    raise RuntimeError("设备未声明 recording.device.v1")
if not robot.supports('recording.device.av.v1'):
    raise RuntimeError("设备未声明 recording.device.av.v1")
if not robot.supports('recording.screen_preview.v1'):
    raise RuntimeError("设备未声明 recording.screen_preview.v1")

import time

# 在设备端录制，并把录制画面显示在设备屏幕上。
recording = robot.recordings.start(
    # av：同时录制音频和视频；duration：请求录制时长，单位秒。
    mode="av", duration=5,
    # True：启用设备屏幕预览，适用于包含视频的 video / av 模式。
    screen_preview=True,
)
try:
    # 等待 5 秒录制并稍留余量。
    time.sleep(5.5)
finally:
    # 无论正常还是异常，都停止录制并等待设备完成收尾。
    recording.stop()
```

### 下载后转换 WAV 或 MP4

```python
from pathlib import Path
from watcherobot.recordings import (
    iter_wrec_records, mux_wrec_to_mp4, write_pcm_wav,
)

# 独立示例：选择设备上已完成的录制，不依赖前面代码块的变量。
if not robot.supports('recording.device.v1'):
    raise RuntimeError("设备未声明 recording.device.v1")
items = robot.recordings.list()
completed = [item for item in items if item.state == 'completed']
if not completed:
    raise RuntimeError("没有已完成录制；先运行设备录制示例")
info = completed[0]  # 应用中按用户选中的真实录制 ID 查找，不能猜 ID。
download = robot.recordings.download(info.id, 'recording-output')
# 按文件名排序读取本次下载目录中的 WREC 分段。
paths = sorted(Path(download.raw_directory).glob("*.wrec"))
# 将分段解析成音视频记录，供下方导出函数消费。
records = iter_wrec_records(paths)
if info.mode == "audio":
    # 纯音频录制导出为主机上的 WAV 文件。
    write_pcm_wav(records, "recording.wav")
else:
    # 含视频的录制导出为 MP4；转换在主机上运行，需要相应媒体依赖。
    mux_wrec_to_mp4(
        # 第一个参数是解析后的记录流，第二个参数是输出文件路径。
        records, "recording.mp4",
        # 使用录制返回的实际宽高，单位像素。
        width=info.width, height=info.height,
        # fps：生成视频使用的帧率；仅 av 模式把音轨一起写入。
        fps=info.fps, with_audio=(info.mode == "av"),
    )
```

items = robot.recordings.list()
for item in items:
    # id：录制 ID；state：录制状态；mode：video / audio / av。
    print(item.id, item.state, item.mode)

**成功标准：** 设备录制须完成 finalizing；主机录制须收到 FLAG_LAST。下载文件不等于 MP4，需按 mode 转换。转换示例独立查询已完成录制，再下载和转换。

**启动应答丢失的限制：** 设备录制的 ID 来自启动应答，超时后可能没有句柄。不要停止目录中的其他录制；保持有限 duration，查询 list/status 核对状态。无法确认本次 ID 就报告“状态未知”，不自动重试启动，也不宣称已停止。这需要 SDK/固件合同补足，skill 不拼私有协议绕过。

**失败与清理：** HostRecording.close 只释放本地接收端，失败时先 stop 再 close。长录制需要周期 heartbeat，建议每 5 秒一次；片段仅演示 5 秒短录制，不直接改成无限时长。status/list 可查询，delete 删除设备文件，仅在用户明确要求时执行。
