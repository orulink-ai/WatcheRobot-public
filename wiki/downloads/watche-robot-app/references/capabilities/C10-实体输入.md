# C10 实体输入

先读 [共同前提 C00](../机器人能力.md)。

**如何选择：** 背部触摸、屏幕点击和滚轮都从 inputs.wait 读取，按 source 分流。

**使用前检查：** 这些是机器人实体输入，不是主机鼠标键盘。背触有 press/release/long_press（实际是否上报取决于固件）；屏幕为 tap；滚轮为 rotate。

### 等待背部触摸

```python
import time

# 在 10 秒轮询窗口内等待背部触摸事件。
deadline = time.monotonic() + 10
while time.monotonic() < deadline:
    try:
        # 每次最多等 1 秒；收到的事件也可能来自其他输入设备。
        event = robot.inputs.wait(timeout=1)
    # 本次没有新事件就继续等待，直到轮询窗口结束。
    except TimeoutError:
        continue
    # 按 source 筛选背部触摸，忽略其他来源。
    if event.source == "back_touch":
        # action：按下、释放、长按等动作；touch_id：触摸传感器标识。
        print(event.action, event.touch_id)
        break
```

### 等待屏幕点击

```python
import time

# 在 10 秒轮询窗口内等待屏幕触摸事件。
deadline = time.monotonic() + 10
while time.monotonic() < deadline:
    try:
        # 单次等待最多 1 秒；此接口接收全部输入来源的事件。
        event = robot.inputs.wait(timeout=1)
    # 1 秒内没有事件时继续轮询。
    except TimeoutError:
        continue
    # 只处理屏幕触摸。
    if event.source == "screen_touch":
        # x、y：屏幕触摸位置，单位为像素。
        print("点击位置：", event.x, event.y)
        break
```

### 等待滚轮

```python
import time

# 在 10 秒轮询窗口内等待滚轮事件。
deadline = time.monotonic() + 10
while time.monotonic() < deadline:
    try:
        # 单次等待上限为 1 秒。
        event = robot.inputs.wait(timeout=1)
    # 暂无事件时继续等待。
    except TimeoutError:
        continue
    # 只处理滚轮来源的事件。
    if event.source == "roller":
        # delta：本次旋转的有符号步进增量；不是绝对角度。
        print("旋转步进：", event.delta)
        break
```

**成功标准：** 收到目标 source 后记录本次动作或坐标。窗口内没有事件要报告“未收到”，不能因程序正常退出认定功能通过。

**失败与清理：** 长期应用使用 D04 的 shutdown_requested 循环和有限 timeout；dropped_events 可观察队列丢失。不要用 sleep 猜测用户已经触摸。
