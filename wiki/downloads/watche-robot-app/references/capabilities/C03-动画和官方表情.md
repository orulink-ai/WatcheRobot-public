# C03 动画和官方表情

先读 [共同前提 C00](../机器人能力.md)。

**如何选择：** 动画目录 ID 选 animation.play；官方表情资源 ID 选 expressions.play_official；作品片段见 C13。

**使用前检查：** animation.available_ids 是设备公告的动画列表。预加载需 animation.prefetch.v1；官方表情需 resource.expression.official。不要把两个目录的 ID 混用。

### 查询、可选预加载、播放动画

```python
from app_support import device_session

# 读取设备公告的动画 ID，避免使用设备上不存在的资源。
ids = robot.animation.available_ids
print("可用动画：", ids)

if not ids:
    raise RuntimeError("设备没有公告可用动画")

animation_id = ids[0]  # 可换成上方列表中的其他 ID
# 只有设备声明支持预加载时才调用；预加载本身不会开始播放。
if robot.supports("animation.prefetch.v1"):
    robot.animation.prefetch(animation_id)

# 播放指定动画，并取得可等待的任务句柄。
with device_session(
    lambda: robot.animation.play(animation_id),
    robot.animation.stop,
) as job:
    # 最多等待 10 秒；持续循环的动画可能需要主动停止。
    job.wait(timeout=10)
```

### 播放官方表情

```python
if not robot.supports('resource.expression.official'):
    raise RuntimeError("设备未声明 resource.expression.official")

# resource_id 必须来自设备官方表情目录，不能直接填任意情绪单词。
resource_id = "your_expression_id"
robot.expressions.play_official(resource_id)
```

**成功标准：** 动画以 Job 终态判断；官方表情调用无 Job，返回只说明命令处理结果，需确认显示。

**失败与清理：** 循环动画不会自然完成，可等待超时后 stop。官方/作品目录可在没有其他 Application 占用时用 watcherobot robot screen list 查询；有应用时该业务请求会进入应用，不能绕过它。查询不到的 ID 保留为待配置项。
