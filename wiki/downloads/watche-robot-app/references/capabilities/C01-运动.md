# C01 运动

先读 [共同前提 C00](../机器人能力.md)。

**如何选择：** 转到目标角度选 move_to；不断更新控制目标选 set_target；播放设备动作资源选 play_action。

**使用前检查：** 这组旧接口没有统一的强制 capability 检查；检查 SDK 方法、设备连接和实际固件支持。角度协议范围 0～180 度，受机械限位约束。action_id 必须来自已安装动作资源，不能用行为 ID 代替。

### 定时移动并等待

```python
from app_support import device_session

# 返回任务句柄 job，可用它等待本次移动任务的结果。
with device_session(
    lambda: robot.motion.move_to(
        # pan_deg：水平目标角度；tilt_deg：俯仰目标角度，单位均为度。
        # 协议角度范围为 0～180 度，实际运动受机械限位约束。
        # duration_ms：请求的运动时长，800 毫秒 = 0.8 秒。
        pan_deg=90, tilt_deg=90, duration_ms=800,
    ),
    robot.motion.stop,
) as job:
    # 最多等待任务结果 5 秒；超时会抛出 TimeoutError。
    job.wait(timeout=5)
```

### 连续更新目标

```python
import time
from app_support import device_session

# 这些是水平轴目标角度（度），不是每次增加的角度；实际受机械限位约束。
angles = (80, 85, 90, 95, 100)
with device_session(
    # 第一次明确被拒绝时不发 stop；应答超时则尝试清理可能已启动的运动。
    lambda: robot.motion.set_target(pan_deg=angles[0]),
    robot.motion.stop,
):
    for angle in angles[1:]:
        time.sleep(0.2)  # 发送间隔（秒），不保证已经到达上一个目标。
        robot.motion.set_target(pan_deg=angle)  # 需要俯仰时另传 tilt_deg。
    time.sleep(0.2)
# 已启动后的异常仍会清理；停止失败不会覆盖原始业务错误。
```

### 播放已安装动作

```python
from app_support import device_session

action_id = "your_action_id"  # 替换为设备已安装的动作 ID
# action_id 指向设备中的动作资源；返回本次播放的任务句柄。
with device_session(
    lambda: robot.motion.play_action(action_id),
    robot.motion.stop,
) as job:
    # 最多等待 10 秒，单位为秒；超时会抛出异常。
    job.wait(timeout=10)
```

**成功标准：** move_to/play_action 返回 Job；等待终态并观察实际运动。set_target 返回不代表已经到位。

**失败与清理：** 仅清理本应用已启动或启动结果未知的运动；首次明确拒绝时不发 stop。profile 参数存在但不要承诺所有固件都实现所选插值曲线。
