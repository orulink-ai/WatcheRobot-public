# C06 麦克风

先读 [共同前提 C00](../机器人能力.md)。

**如何选择：** 保存一段录音选 record_pcm；逐帧处理选 open_pcm；只有需要编码包时选 open。

**使用前检查：** open 返回原始 Opus 包；open_pcm 在主机解码为 16 kHz、单声道、16 位 PCM。麦克风是设备麦克风，不是电脑麦克风。

### 读取原始 Opus 包

```python
# 打开设备麦克风；退出 with 时关闭该麦克风流。
with robot.microphone.open() as microphone:
    # 最多等待一个音频包 2 秒；返回的是压缩的 Opus 数据，不是 PCM。
    packet = microphone.read(timeout=2)
    # sequence：包序号；data：音频字节，len(...) 得到字节数。
    print(packet.sequence, len(packet.data))
```

### 读取 PCM 帧

```python
# 打开麦克风并在主机端解码；得到 16 kHz、单声道、16 位 PCM。
# 退出 with 时关闭麦克风流。
with robot.microphone.open_pcm() as microphone:
    # 最多等待一个解码后的 PCM 帧 2 秒。
    frame = microphone.read(timeout=2)
    print("PCM 字节数：", len(frame.data))
    # dropped_frames：丢帧计数；decode_failures：解码失败计数，可用于排查质量。
    print("丢帧 / 解码失败：",
          microphone.dropped_frames, microphone.decode_failures)
```

### 录制三秒 WAV

```python
recording = robot.microphone.record_pcm(
    # duration：目标录音时长 3 秒；timeout：采集等待上限 5 秒。
    duration=3, timeout=5,
)
# 将收到的 PCM 保存为主机上的 WAV 文件；文件内会包含正确的音频头。
recording.save("microphone.wav")
# 实际录到的音频时长，单位为秒。
print("秒数：", recording.duration_seconds)
# 查看采集过程中累计的丢帧和解码失败数量。
print("丢帧 / 解码失败：",
      recording.dropped_frames, recording.decode_failures)
```

**成功标准：** read 得到非空数据；录音时长/格式正确，保存的 WAV 可播放；查看 dropped_frames、decode_failures。

**失败与清理：** with 退出关闭麦克风；单次 read 超时按业务决定继续还是结束。record_pcm 的 timeout 是收集预算，不完整会报错。不要使用 microphone.record()，当前接口拒绝原始 Opus 录制。
