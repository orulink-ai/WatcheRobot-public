# C04 程序化表情

先读 [共同前提 C00](../机器人能力.md)。

**如何选择：** 不使用 SD 动画，直接调整眼睛、视线、装饰。支持参数、像素装饰、矢量装饰；嘴型可跟随 RTC 或设备支持的本地 PCM 播放。

**使用前检查：** start/update/stop 要求 expression.runtime.v3。预设 standby/thinking/speaking；风格 watcher/watcher_compact/watcher_focus/watcher_open/watcher_pulse；tag 可用 none/thinking/question/love。装饰可用 none/halo/devil_horns/ninja_mask/hero_mask/eyepatch/antenna/custom_pixel/custom_vector。

### 参数化眼睛

```python
from app_support import device_session

if not robot.supports('expression.runtime.v3'):
    raise RuntimeError("设备未声明 expression.runtime.v3")

import time

with device_session(
    lambda: robot.expression_runtime.start(
        # standby：初始表情预设；style：表情风格；auto_blink：启用自动眨眼。
        "standby", style="watcher", auto_blink=True,
    ),
    robot.expression_runtime.stop,
):
    robot.expression_runtime.update(
        # preset：切换为思考表情；gaze_x：水平视线偏移，范围 -1～1，0 为居中。
        preset="thinking", gaze_x=0.5,
        # 左右眼开合比例：1 为基准，0.8 更闭合，1.1 更睁开。
        left_openness=0.8, right_openness=1.1,
        # tag：问号标签；accessory：光环装饰，名称需在当前运行时中受支持。
        tag="question", accessory="halo",
        # color：RGB 十六进制颜色；transition_ms：表情过渡时间，单位毫秒。
        color="#4DA3FF", transition_ms=300,
    )
    # 保持当前表情 2 秒。
    time.sleep(2)
```

### 自定义像素装饰

```python
from app_support import device_session

if not robot.supports('expression.runtime.v3'):
    raise RuntimeError("设备未声明 expression.runtime.v3")

import time

# 51×51 位图：这里画一条横线；按行优先、每字节高位在前。
# 51×51 = 2601 个像素，每像素 1 位，向上取整需 326 字节。
mask = bytearray(326)
# 在第 25 行点亮 x=10～40 的像素；行列下标从 0 开始。
for x in range(10, 41):
    # 将二维坐标换成位索引；每行占 51 位。
    bit = 25 * 51 + x
    # 定位所在字节，并按高位在前的顺序将该像素置为 1。
    mask[bit // 8] |= 1 << (7 - bit % 8)

with device_session(
    lambda: robot.expression_runtime.start(
        # 使用待机表情，并启用自定义像素装饰。
        "standby", accessory="custom_pixel",
        # 将 326 字节转成 652 个十六进制字符，作为位图参数。
        custom_accessory_mask=mask.hex(),
        # front：装饰显示在眼睛前方；back 表示显示在后方。
        custom_accessory_layer="front",
    ),
    robot.expression_runtime.stop,
):
    # 显示 2 秒。
    time.sleep(2)
```

### 自定义矢量装饰

```python
from app_support import device_session

if not robot.supports('expression.runtime.v3'):
    raise RuntimeError("设备未声明 expression.runtime.v3")

import time

# 版本 1、1 条笔画、线宽 4、3 个点；坐标为大端整数。
path = bytearray([1, 1, 4, 3])
# 三个点依次连成折线；412×412 画布上的坐标范围为 0～411。
for x, y in [(80, 80), (200, 200), (332, 80)]:
    # 每个坐标用 2 字节无符号大端整数编码，依次写入 x 和 y。
    path.extend(x.to_bytes(2, "big"))
    path.extend(y.to_bytes(2, "big"))

with device_session(
    lambda: robot.expression_runtime.start(
        # 使用待机表情，并启用自定义矢量装饰。
        "standby", accessory="custom_vector",
        # 将包含版本、笔画信息和坐标的二进制路径转为十六进制字符串。
        custom_vector_path=path.hex(),
        # front：装饰绘制在眼睛前方；back 表示后方。
        custom_accessory_layer="front",
    ),
    robot.expression_runtime.stop,
):
    # 显示 2 秒。
    time.sleep(2)
```

### RTC 播放驱动嘴型

**SDK 检查：** 按实际安装报告确认接口。项目 `sdk-requirements.json` 必须增加 `expression_runtime.set_audio_follow`；检查通过后再连接设备。

嘴型跟随设备实际播放的 PCM，静音时闭嘴；不使用浏览器麦克风音量估算。启用后保留禁用/清理路径，换设备后不要用旧会话清理新设备。与音频通话、拍照组合时见 [C12](C12-RTC.md)。

```python
if not robot.supports('expression.audio_follow.v1'):
    raise RuntimeError("设备未声明 expression.audio_follow.v1")

import time

# 只跟随真正写入设备喇叭的 RTC 音频；先按 C12 建立真实音频会话。
from app_support import device_session
with device_session(
    lambda: robot.expression_runtime.set_audio_follow(True),
    lambda: robot.expression_runtime.set_audio_follow(False),
):
    time.sleep(5)  # 展示窗口，单位秒；没有实际播放时不能据此证明嘴型有效。
```

### 本地音频驱动嘴型

不建立 RTC。设备必须同时声明下面两项能力；不能仅凭 v1 就对本地音频启用嘴型。

```python
from app_support import device_session

for capability in ('expression.audio_follow.v1', 'expression.audio_follow.local_pcm.v1'):
    if not robot.supports(capability):
        raise RuntimeError(f"设备未声明 {capability}")

with device_session(
    lambda: robot.expression_runtime.set_audio_follow(True),
    lambda: robot.expression_runtime.set_audio_follow(False),
):
    # prompt.wav 是主机上的音频；SDK 解码后在设备播放。
    with device_session(lambda: robot.audio.play_file("prompt.wav"), robot.audio.stop) as playback:
        playback.wait(timeout=playback.expected_duration_seconds + 10)  # 秒。
# 正常结束或异常时停止本应用播放，并关闭嘴型跟随。
```

可选眼部情绪：只有设备声明 `expression.audio_follow.v2` 时，才传 `set_audio_follow(True, emotion=2)`；`emotion` 是 0–6 的整数，仅改变眼部情绪，不驱动嘴型时钟。关闭使用 `set_audio_follow(False)`，不传 emotion。需要此参数时先检查 capability，不静默忽略用户指定的情绪。

**成功标准：** 实际画面符合参数；stop 释放自定义显示，返回设备内置显示行为。RTC 嘴型需实际听到播放并观察同步，本地文件/PCM 另需下节的设备能力。

**失败与清理：** 不要同时启动动画、作品与程序化表情争抢屏幕。start 成功后修改用 update。pixel 为 51×51、326 字节；vector 为 412×412 坐标，最多 12 笔、单笔 48 点、总计 192 点、线宽 1～48。

### 其他参数怎么选

`start(preset, ...)` 首次接管显示，`update(...)` 只更新指定字段，不重复 start。

| 参数 | 单位或范围 |
|---|---|
| gaze_x / gaze_y | -1～1，0 居中 |
| openness；left_openness / right_openness | 总开合 0.05～1.2；单眼 0.1～1.5 |
| spacing；scale；scale_x / scale_y | 间距 0.4～1.6；统一缩放 0.5～1.5；独立缩放 0.75～2.2 |
| stroke；roundness | 线条 0.5～2；圆角 0～1 |
| tilt_deg；left_tilt_deg / right_tilt_deg | -30～30 度，是眼睛倾斜，不是云台角度 |
| left/right_upper/lower_lid_y | -80～80 逻辑坐标；对应 *_rotation_deg 为 -45～45 度 |
| auto_blink；blink_interval_ms / blink_duration_ms | 自动眨眼开关；间隔和持续毫秒数 |
| accessory_scale / accessory_x / accessory_y / accessory_rotation_deg | 装饰缩放、偏移和旋转，选参数前检查当前 SDK 签名与校验范围 |
| color；transition_ms；sphere_strength | #RRGGBB；过渡毫秒数；球面投影强度 0～1 |
