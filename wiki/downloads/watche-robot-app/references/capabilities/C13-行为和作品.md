# C13 行为和作品

先读 [共同前提 C00](../机器人能力.md)。

**如何选择：** 多种设备反馈组成的行为选 behavior.play；Creator 作品整体选 works.play；作品中的表情轨道片段选 works.play_expression。

**使用前检查：** behavior_id、work_id、clip_id 必须来自对应资源。作品片段需要 resource.work.expression.play。work_id 是小写字母开头、最多 23 个小写字母/数字/下划线；clip_id 是作品导出时的稳定片段标识，不是文件名或哈希。

### 播放行为

```python
from app_support import device_session

behavior_id = "your_behavior_id"  # 换成已安装行为 ID。
# behavior_id：设备已有的行为资源；repeat=1：完整播放一遍。
with device_session(
    lambda: robot.behavior.play(behavior_id, repeat=1),
    robot.behavior.stop,
) as job:
    # 最多等待行为任务结果 10 秒。
    job.wait(timeout=10)
```

### 播放完整作品

```python
work_id = "your_work_id"  # 换成已安装作品 ID。
# work_id 是设备已安装的作品标识，不是本机文件路径。
# 播放整个作品；命令返回表示请求已处理，不代表作品已播放完毕。
robot.works.play(work_id)
```

### 播放作品表情片段

```python
if not robot.supports('resource.work.expression.play'):
    raise RuntimeError("设备未声明 resource.work.expression.play")

# 替换成设备已经安装的作品 ID。
work_id = "your_work_id"
# clip_id：作品内部的表情片段 ID，示例为 main，需与实际资源一致。
# 只请求播放这个表情片段；返回不代表片段已经播放完毕。
robot.works.play_expression(work_id, clip_id="main")
```

**成功标准：** 行为返回 Job 并可 stop；作品接口返回不代表时间线已结束，应确认实际效果。用户没有资源 ID 时先确认已安装资源，不默认烧录新资源。

**失败与清理：** 不要用动作 ID 调 behavior.play。works.delete(work_id) 是删除设备作品，仅用户要求时调用。不要编造 works.stop：当前高层接口没有这个方法。
