# C02 灯光

先读 [共同前提 C00](../机器人能力.md)。

**如何选择：** 常亮选 set_color；重复变化选 play_effect。

**使用前检查：** 确认设备支持目标灯区。color 使用 #RRGGBB，brightness 为 0～1；zone 使用 all/side/bottom。灯效名称可用 breathing、blink、rainbow、status_pulse，仍需匹配固件。

### 常亮两秒

```python
import time
from app_support import device_session

with device_session(
    lambda: robot.lights.set_color(
        "#4DA3FF",  # RGB 十六进制颜色
        brightness=0.5,  # 0～1 的亮度比例
        zone="side",  # side=侧灯，bottom=底灯，all=全部灯区
    ),
    robot.lights.off,  # 正常结束或启动应答丢失都尝试关灯。
):
    time.sleep(2)  # 显示 2 秒
```

### 底灯呼吸三次

```python
from app_support import device_session

with device_session(
    lambda: robot.lights.play_effect(
        # 灯效名称：breathing 表示呼吸灯。
        "breathing",
        # color：RGB 十六进制颜色；brightness：0～1 的亮度比例。
        color="#00FF80", brightness=0.6,
        # zone：bottom 为底灯；period_ms：单个周期的毫秒数。
        # repeat：重复 3 次；设为 0 表示持续循环，需要主动停止。
        zone="bottom", period_ms=800, repeat=3,
    ),
    robot.lights.off,
) as job:
    # 等待灯效任务结果，最多 6 秒。
    job.wait(timeout=6)
```

**成功标准：** 灯效 Job 正常结束；灯区、颜色、亮度应由实际观察确认。off 关闭可控制灯光。

**失败与清理：** 有限次灯效使用足够的等待时间；repeat=0 持续循环，业务结束主动 off。常亮也要在产品退出路径中 off。
