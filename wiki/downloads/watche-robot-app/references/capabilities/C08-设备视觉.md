# C08 设备视觉

先读 [共同前提 C00](../机器人能力.md)。

**如何选择：** 先查询模型和健康状态；切换模型不会启动推理；只要检测框选 start_inference；需要同帧 JPEG 加 preview=True。

**使用前检查：** status/health/active_model/capabilities 要求 vision.status.v1；models 要求 vision.models.v1；select_model 要求 vision.model.select.v1；推理要求 vision.inference.v1，预览另需 vision.inference.preview.v1。模型 ID 为查询返回的整数，不是模型名称。

### 查询并选择已验证资源

```python
if not robot.supports('vision.status.v1'):
    raise RuntimeError("设备未声明 vision.status.v1")
if not robot.supports('vision.models.v1'):
    raise RuntimeError("设备未声明 vision.models.v1")

# 查询视觉模块状态，不会启动推理。
status = robot.vision.status()
# backend：推理后端；health：健康状态；capabilities：视觉模块能力。
print(status.backend, status.health, status.capabilities)
print("当前模型：", robot.vision.active_model())

# 读取设备模型目录；model_id 用于后续选择或启动推理。
models = robot.vision.models()
for model in models:
    # verified 表示模型资源通过校验，不代表识别准确率已经验收。
    print(model.model_id, model.name, model.verified)

# 示例选择第一个通过资源校验的模型；实际应用应按任务选择合适的模型。
model = next((m for m in models if m.verified), None)
if model is None:
    raise RuntimeError("没有可运行的已验证模型")
# 保存模型 ID，供下方切换模型、推理和预览示例复用。
model_id = model.model_id
```

### 切换模型

```python
# 独立查询模型；本例演示首个已验证模型，不代表它符合业务识别目标。
if not robot.supports('vision.models.v1'):
    raise RuntimeError("设备未声明 vision.models.v1")
models = robot.vision.models()
model = next((item for item in models if item.verified), None)
if model is None:
    raise RuntimeError("没有已验证模型；先检查设备模型资源")
model_id = model.model_id  # 正式应用按返回的 name/task 选择所需模型。

if not robot.supports('vision.model.select.v1'):
    raise RuntimeError("设备未声明 vision.model.select.v1")
if not robot.supports('vision.status.v1'):
    raise RuntimeError("设备未声明 vision.status.v1")

# 使用本代码块刚查询得到的 model_id。
# 先结束占用相机的会话，再切换模型；此调用只选择模型，不启动推理。
selected = robot.vision.select_model(model_id)
print("切换后的模型：", selected)
```

### 只获取推理结果

```python
# 独立查询模型；本例演示首个已验证模型，不代表它符合业务识别目标。
if not robot.supports('vision.models.v1'):
    raise RuntimeError("设备未声明 vision.models.v1")
models = robot.vision.models()
model = next((item for item in models if item.verified), None)
if model is None:
    raise RuntimeError("没有已验证模型；先检查设备模型资源")
model_id = model.model_id  # 正式应用按返回的 name/task 选择所需模型。

if not robot.supports('vision.inference.v1'):
    raise RuntimeError("设备未声明 vision.inference.v1")

import time

# 使用本代码块选出的模型启动推理；退出 with 时停止推理会话。
# 该能力返回识别结果，不会自动控制云台跟踪。
with robot.vision.start_inference(model_id) as session:
    # 以 10 秒作为轮询窗口；每次查询本身另有 timeout。
    deadline = time.monotonic() + 10
    while time.monotonic() < deadline:
        # 单次查询最多等待 2 秒；尚无推理结果时可能返回 None。
        result = session.latest(timeout=2)
        if result is not None:
            # model_id：结果所用模型；boxes：检测框集合，坐标以中心点表达。
            print(result.model_id, result.boxes)
            break
        # 暂无结果时等待 0.1 秒再查询，避免持续占用线程。
        time.sleep(0.1)
    else:
        raise TimeoutError("推理尚未返回结果")
```

### 获取检测框及同帧 JPEG

```python
# 独立查询模型；本例演示首个已验证模型，不代表它符合业务识别目标。
if not robot.supports('vision.models.v1'):
    raise RuntimeError("设备未声明 vision.models.v1")
models = robot.vision.models()
model = next((item for item in models if item.verified), None)
if model is None:
    raise RuntimeError("没有已验证模型；先检查设备模型资源")
model_id = model.model_id  # 正式应用按返回的 name/task 选择所需模型。

if not robot.supports('vision.inference.v1'):
    raise RuntimeError("设备未声明 vision.inference.v1")
if not robot.supports('vision.inference.preview.v1'):
    raise RuntimeError("设备未声明 vision.inference.preview.v1")

import time
from pathlib import Path

# 启动推理预览；退出 with 时自动停止会话。
with robot.vision.start_inference(
    # model_id：设备中的模型 ID；preview=True：同时返回对应帧的 JPEG。
    model_id, preview=True,
) as session:
    # 设置 10 秒轮询窗口，单次请求还有各自的等待上限。
    deadline = time.monotonic() + 10
    while time.monotonic() < deadline:
        # 单次查询等待上限为 2 秒。
        result = session.latest(timeout=2)
        # 同时拿到推理结果和预览图后，才保存本帧。
        if result is not None and result.jpeg is not None:
            # JPEG 保存到主机文件；boxes 对应这张图像中的检测结果。
            Path("inference.jpg").write_bytes(result.jpeg)
            print(result.boxes)
            break
        # 暂无完整结果时，间隔 0.1 秒重试。
        time.sleep(0.1)
    else:
        raise TimeoutError("推理预览尚未返回结果")
```

**成功标准：** 有 result 才表示得到推理结果；空 boxes 可以是有效的“未检测到”。verified 表示资源校验，不代表算法准确率。普通推理不控制云台。

**失败与清理：** 三个执行片段均自行查询并选择模型，不依赖上一个代码块。实际应用按目标选择模型，不能假设首个模型就是人脸识别。with 退出关闭会话；也可用 vision.stop_inference。中心点检测框与 C09 左上角人脸框不能混用。
