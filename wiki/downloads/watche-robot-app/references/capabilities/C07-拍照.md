# C07 拍照

先读 [共同前提 C00](../机器人能力.md)。

**如何选择：** 只获取 JPEG 选 capture；用户需要拍照状态动画和快门反馈选 capture_with_feedback。

**使用前检查：** 先按 D03 检查所选方法是否存在。带反馈另需 camera.capture.feedback.v1；普通拍照没有同样的能力前置。width/height/quality 默认 0 表示交给设备默认配置，不承诺固定分辨率。timeout 单位秒。

### 普通拍照

```python
# 普通拍照：返回 JPEG，不启用拍照状态动画和快门反馈。
# timeout：本次拍照等待预算，单位秒，包含相机协调、命令与图像接收等待。
image = robot.camera.capture(timeout=10)
# 保存到运行 Application 的主机路径；image.data 是 JPEG 原始字节。
image.save("photo.jpg")
print("JPEG 字节数：", len(image.data))
```

### 带状态反馈拍照

**SDK 检查：** 以实际安装报告为准。项目 `sdk-requirements.json` 必须增加 `camera.capture_with_feedback`；检查通过后再连接设备，不能静默改成普通拍照。

```python
# 版本号不能代替实际方法检查；带反馈不可用时不自动改为普通拍照。
if not callable(getattr(robot.camera, "capture_with_feedback", None)):
    raise RuntimeError("当前安装的 SDK 没有 camera.capture_with_feedback")
# 此调用需要固件支持带反馈拍照；不支持时明确报错，不自动改成普通拍照。
if not robot.supports("camera.capture.feedback.v1"):
    raise RuntimeError("当前固件不支持带状态反馈的拍照")

# 拍照时启用状态动画和快门反馈；timeout 为等待预算，单位秒。
image = robot.camera.capture_with_feedback(timeout=10)
# 返回值仍为 JPEG 图像，保存到主机上的指定文件。
image.save("photo-with-feedback.jpg")
```

**成功标准：** 收到 JPEG 并保存/展示；打开文件验证可解码且来自本次拍摄。完整应用模板见开发步骤 D04。

**失败与清理：** 带反馈不支持时不得自动改普通拍照。摄像头视频会话、推理、跟踪或录制可能造成冲突；先释放本应用占用。普通拍照在配套固件上可与音频 RTC 共存；反馈拍照会被任何活动 RTC（包括 audio）拒绝，须先结束本应用 RTC。视频 RTC 占用相机，不能同时拍照。
