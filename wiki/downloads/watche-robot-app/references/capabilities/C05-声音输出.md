# C05 声音输出

先读 [共同前提 C00](../机器人能力.md)。

**如何选择：** 设备已安装音效选 play；主机文件选 play_file；已生成的 PCM 选 play_pcm；逐段产生的 PCM 选 open_stream。

**使用前检查：** sound_id 必须存在。主机文件 WAV/MP3/OGG 由 SDK 解码；输出为 24 kHz 单声道 S16LE PCM，单次 PCM 上限 4 MiB。普通音频播放与独立麦克风采集不要同时启动；RTC 全双工另见 C12。

### 设备音效

```python
from app_support import device_session

sound_id = "your_sound_id"  # 替换为设备已安装的音效 ID
# 播放设备已有的音效资源；sound_id 不是本机音频文件路径。
with device_session(
    lambda: robot.audio.play(sound_id),
    robot.audio.stop,
) as job:
    # 最多等待播放任务结果 10 秒。
    job.wait(timeout=10)
```

### 主机音频文件

```python
from app_support import device_session

# prompt.wav 是运行 Application 的主机上的文件路径；音频发送到设备播放。
with device_session(
    lambda: robot.audio.play_file("prompt.wav"),
    robot.audio.stop,
) as playback:
    playback.wait(
        # 根据预计音频时长再留出 10 秒等待余量，timeout 单位为秒。
        timeout=playback.expected_duration_seconds + 10,
    )
```

### 原始 PCM

```python
from pathlib import Path
from app_support import device_session

# 读取纯 PCM 文件，不能包含 WAV 文件头。
pcm_bytes = Path("speech.pcm").read_bytes()
with device_session(
    lambda: robot.audio.play_pcm(
        # pcm_bytes：原始 PCM 音频字节；sample_rate_hz：24000 表示 24 kHz。
        pcm_bytes, sample_rate_hz=24000,
        # 单声道，每个采样 2 字节，有符号 16 位小端 PCM。
        channels=1, sample_width_bytes=2,
    ),
    robot.audio.stop,  # 本应用独占普通音频；启动超时也尝试停止。
) as playback:
    playback.wait(
        # 预计播放时长加 10 秒余量，单位为秒。
        timeout=playback.expected_duration_seconds + 10,
    )
```

**成功标准：** 设备音效返回 Job，文件和 PCM 返回 AudioPlayback；等待结果并确认设备发声。expected_duration_seconds 是预计秒数，不是完成证据。

**失败与清理：** 结束用 audio.stop 或本次 playback.cancel。no_capacity 先释放本应用音频/录音/RTC 占用，再重试一次。不把 WAV 文件头作为 PCM 数据发送。


### 连续 PCM 播放

用于分段 TTS 等持续产生音频的应用，一个回复共用一条播放流。将 `audio.open_stream`、`audio_stream.write`、`audio_stream.finish`、`audio_stream.wait`、`audio.stop` 加入 requirements。

```python
from app_support import device_session

if not robot.supports('audio.stream.continuous.v1'):
    raise RuntimeError("设备未声明 audio.stream.continuous.v1")

# 示例从已有纯 PCM 文件分块读取；接 TTS 时替换成实际 PCM 数据源。
# 格式固定为 24 kHz、单声道、有符号 16 位小端，每块必须包含完整采样。
with open("speech.pcm", "rb") as source:
    with device_session(
        # max_bytes：整条流的字节上限，4 MiB 约 87 秒；不是单块上限。
        lambda: robot.audio.open_stream(max_bytes=4 * 1024 * 1024),
        robot.audio.stop,  # 成功或未知启动后的异常均清理；明确拒绝不停止其他会话。
    ) as playback:
        while chunk := source.read(4096):  # 每次读取 4096 字节，不整段加载进内存。
            playback.write(chunk).result(timeout=10)  # 秒；等上一块写完才发下一块。
        playback.finish().result(timeout=10)  # 声明输入结束；仍需等待设备完成播放。
        playback.wait(timeout=playback.expected_duration_seconds + 10)
```

总量超过 max_bytes、空流、半个采样或传输失败应报错，不截断伪装成功。只有收到并校验完成结果后才算播放结束；实际声音另验。持有本次句柄时可用 `playback.cancel()` 取消，失败则保留清理状态并重试本次停止，不能立刻开新流。异步 TTS 数据源留在应用自己的事件循环，等待写入 Future 用 `asyncio.wrap_future`；不要把异步生成器搬进工作线程。托管停止的时间限制见 D06。
